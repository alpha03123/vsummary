# VSummary B站浏览器插件

在观看 Bilibili 视频时，这个插件可以把 VSummary 打开在浏览器侧边栏中。你不需要来回切换页面，就能查看视频概况、章节、思维导图、知识卡片和笔记，也可以直接围绕当前视频提问。

## 安装

1. 先启动 VSummary，并确认浏览器能够打开 `http://127.0.0.1:4173`。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 打开页面右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择当前这个 `bilibili-sidepanel` 文件夹。

安装完成后，建议把“VSummary B站总结”固定到浏览器工具栏。首次安装后，请刷新已经打开的 Bilibili 视频页面。

## 使用

1. 保持 VSummary 在后台运行。
2. 打开任意 Bilibili 视频播放页。
3. 点击浏览器工具栏中的“VSummary B站总结”图标。
4. VSummary 会在侧边栏中打开，并自动切换到当前视频。

首次打开的视频会出现在 VSummary 的“B站导入”系列中。切换视频或分 P 后，侧边栏也会自动跟随。点击章节或转写中的时间位置，可以让 Bilibili 播放器跳转到对应进度。

遇到无法打开侧边栏、识别不到视频或连接失败时，请查看[浏览器插件安装与使用教程](../../docs/browser-extension.md)。
